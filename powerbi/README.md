# Power BI

This folder contains the semantic model, 19 DAX measures, page design, mobile layout, and reconciliation checklist.

A `.pbix` file is not included because Power BI Desktop was unavailable. The dashboard image is a preview built from verified summary data.

To build the report:

1. Import the Oracle sources listed in `model.md`.
2. Create the documented relationships.
3. Add the measures from `dax_measures.dax`.
4. Build the four pages described in `model.md`.
5. Reconcile cards and peer medians to the processed CSV files.
6. Test interactions and mobile layout before publishing the `.pbix`.
